# Upgrade from API Platform 4.1 to 4.2

- OpenAPI `allowReserved` and `allowEmptyValue` now default to null → distinguish unset from explicit false in schema checks.
- Where a parameter has a default, send an explicit `0` or `false` and then omit the parameter. The fix for falsy values preserves the supplied value. Remove client-side workarounds that previously encoded it as the default.
- If a schema decorator traverses definitions inline, resolve `$ref` when reading shared subschemas. Exercise two operations referencing the same definition.
