# Upgrade from API Platform 3.1 to 3.2

- When merging the 3.2 Symfony recipe, `event_listeners_backward_compatibility_layer: false` switches request handling to providers/processors. For an operation depending on a custom kernel listener, exercise its side effect before accepting that switch. If the new inflector changes an existing public route, `keep_legacy_inflector: true` retains the Doctrine inflector on this series.
- Preserve any required `application/json` under `formats.json`. The recipe places `application/vnd.openapi+json` under `docs_formats.jsonopenapi`. With `rfc_7807_compliant_errors` or `standard_put` enabled by the recipe, compare an invalid write and a PUT omitting a previously populated field.
