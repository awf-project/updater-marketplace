# Upgrade from API Platform 3.2 to 3.3

- `MissingConstructorArgumentsException` text in tests or clients → send a DTO missing a required argument and verify the public error contract.
- For asynchronous operations whose Messenger handlers read the request from API Platform’s context stamp, pass the specific serializable values the handler uses. Round-trip the envelope through the configured transport serializer before invoking the handler.

[Release notes](https://api-platform.com/docs/changelog/#v330)
