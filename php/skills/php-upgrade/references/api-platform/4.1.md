# Upgrade from API Platform 4.0 to 4.1

- Hydra consumers → compare resource short names in `hydra:title`, label fields, and schemas generated from error and validation classes.
- For Laravel installations that set `cache.default` to a shared store and rely on it for API Platform metadata, 4.1 defaults to the file cache. Set `cache` in `config/api-platform.php` to the shared store if workers need it. Verify with `app.debug` disabled, because debug mode selects the array cache.

[Release notes](https://api-platform.com/docs/changelog/#v410)
