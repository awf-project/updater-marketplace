# Upgrade from API Platform 2.7 to 3.0

- Mappings still use ApiPlatform Core or legacy item and collection operations. [Resource metadata on 2.7](#resource-metadata-on-27)
- The app has providers, persisters, transformers, filters, or operation-aware extensions. [State and Doctrine extensions](#state-and-doctrine-extensions)
- The app decorates IriConverterInterface or exposes custom identifiers. [Custom identifiers and IRIs](#custom-identifiers-and-iris)

## Resource metadata on 2.7

Use 2.7 as the metadata bridge. Run `api:upgrade-resource` where it supports the current mapping and review the diff before applying it. Move operations to `ApiPlatform\Metadata` classes and preserve custom route names, URI variables, identifiers, and security expressions.

Disable `metadata_backward_compatibility_layer` on 2.7 and exercise the resulting metadata. Remove the option before running 3.0. Compare generated routes, OpenAPI, and serializer contexts with the existing API contract.

## State and Doctrine extensions

Replace `DataProviderInterface` implementations with `ApiPlatform\State\ProviderInterface::provide()` and persisters with `ApiPlatform\State\ProcessorInterface::process()`. When porting transformations for input/output DTOs, preserve validation and domain side effects at the corresponding operation boundary. For affected Doctrine extension and filter signatures, accept the metadata `Operation` object and use its name when porting name-based branches. Test each affected operation.

Compare a successful read, a valid write, an invalid DTO, and an unauthorized operation. Check persistence effects as well as HTTP status.

## Custom identifiers and IRIs

If clients send a scalar relation ID via the old `allow_plain_identifiers` option, normalize that input to the relation IRI before denormalization, or migrate those clients to send IRIs. Test the existing write payload.

Move the decorator to `ApiPlatform\Api\IriConverterInterface` and adapt its signatures to the target version. Test item to IRI and IRI to item with the external URI variables and subresources in use. Include a missing entity and a malformed identifier.
