# Upgrade from API Platform 3.0 to 3.1

- For positional arguments on `Get`, `Query`, `Operation`, or `ApiProperty`, convert each argument using its **source-version** parameter name before the upgrade. The order changed. Compare the resulting route, security and serialization metadata.
- `openapiContext` on resource metadata → use `openapi` with named attribute arguments. Diff schema and operations.
