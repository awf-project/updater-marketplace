# Upgrade from Symfony 7.4 to 8.0

- The project crosses Symfony 7.4 to 8.0. [Dependencies and configuration](#dependencies-and-configuration)
- Service wiring uses tagged attributes, YAML tags, or compiler passes. [Dependency injection](#dependency-injection)
- Clients submit URL values or custom Messenger exceptions are installed. [Forms validation and workers](#forms-validation-and-workers)

## Dependencies and configuration

Use PHP 8.4+ in the runtime that runs Composer as well as production. Resolve the 7.4 deprecations before bumping the framework. Check Flex recipes and merge app customizations before compiling and warming the production container. Change imported `errors.xml` and `webhook.xml` under `@FrameworkBundle/Resources/config/routing/` to `errors.php` and `webhook.php`. Do the same for active WebProfiler `wdt.xml` and `profiler.xml` imports in dev. Compare `debug:router --env=dev` and `--env=prod` for the affected routes. [Symfony 8.0 requirements](https://symfony.com/releases/8.0)

## Dependency injection

Replace `#[TaggedIterator]` and `#[TaggedLocator]` with `#[AutowireIterator]` and `#[AutowireLocator]`. Preserve tag, index, priority, and excluded services. Convert YAML `!tagged` to `!tagged_iterator`. Test the resolved iterable or locator with at least two candidates when ordering matters.

If a compiler pass uses `getAutoconfiguredAttributes()`, inspect `getAttributeAutoconfigurators()` and verify which services get the expected tags. Check custom aliases for dependencies such as `RateLimiterFactory`, whose autowiring now uses `RateLimiterFactoryInterface`.

## Forms validation and workers

Review `UrlType` defaulting `default_protocol` to null and the `Url` constraint defaulting `requireTld` to true. Compare normalized values and validation results for a bare hostname, an internal host, and a fully qualified URL. Pin the options only where the old behavior is required.

For custom `RecoverableExceptionInterface` implementations, account for `getRetryDelay()` and verify the worker's delay or configured fallback. If a monitoring script parses `messenger:stats`, replace removed text output with a supported format.
