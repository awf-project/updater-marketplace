# Upgrade from Symfony 6.4 to 7.0

- The application crosses the Symfony 6 to 7 boundary. [Preparation on 6.4](#preparation-on-64)
- Services implement ContainerAwareInterface or use ContainerAwareTrait. [Service wiring](#service-wiring)
- The app uses Doctrine route annotations or static command metadata. [Routes and console contracts](#routes-and-console-contracts)

## Preparation on 6.4

Confirm PHP 8.2+ and resolve applicable 6.4 deprecations under the app's HTTP, worker, and console paths. Check third-party bundles against the target and align Flex's `extra.symfony.require` with the selected packages.

## Service wiring

Replace `ContainerAwareInterface` and `ContainerAwareTrait` with injected dependencies. Setter injection annotated only with `@required` also stops working. Use `#[\Symfony\Contracts\Service\Attribute\Required]` (or import `Required`) on the setter and exercise a path that reads the initialized dependency. If an optional service or lazy lookup was part of behavior, preserve that dependency contract using the existing container facilities. Compile each affected environment and execute the entry point that previously looked up the service.

## Routes and console contracts

Migrate annotations to attributes and custom loaders to `AttributeClassLoader`. Compare `debug:router` output for names, defaults, requirements, methods, and order. For `Command::$defaultName` or `$defaultDescription`, use `#[AsCommand]` and invoke the names and aliases used by jobs. [Symfony 7.0 requirements](https://symfony.com/releases/7.0)
