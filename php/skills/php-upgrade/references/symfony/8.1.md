# Upgrade from Symfony 8.0 to 8.1

- Remove the deprecated `security.erase_credentials` option and reads of `security.authentication.manager.erase_credentials`. For a custom user that held transient credentials, inspect its serialized session representation after login.
- Serializer date-time constructor fallback → declare formats or convert inputs at the boundary. Test accepted zones and malformed values.
- If a Messenger transport implements `ReceiverInterface::get()` or `QueueReceiverInterface::getFromQueues()`, mirror the new `$fetchSize` argument and forward it through decorators. Verify a worker consumes a batch without dropping envelopes.
- Custom `InputArgument` or `InputOption` wrappers → account for `mixed` defaults when mirroring constructor signatures. Remove mutually exclusive required/optional modes and test absent and explicit values.
