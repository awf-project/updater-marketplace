# Upgrade from Symfony 7.0 to 7.1

- `ContainerConfigurator::import()` in `prependExtension()` → the import now prepends configuration. If a bundle’s imported value used to win, put the intended override in app config and inspect `debug:config <extension>` with both values present.
- `#[TaggedIterator]` or `#[TaggedLocator]` → use `#[AutowireIterator]` or `#[AutowireLocator]`. Preserve tag, index, and priority.
- Enabled `framework.rate_limiter` → align `symfony/rate-limiter` to 7.1+ and test permitted and throttled requests.

[7.1.0 release](https://symfony.com/blog/symfony-7-1-0-released), [Upgrade notes](https://github.com/symfony/symfony/blob/v7.1.0/UPGRADE-7.1.md)
