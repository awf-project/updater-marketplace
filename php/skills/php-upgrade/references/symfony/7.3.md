# Upgrade from Symfony 7.2 to 7.3

- Validator constraint option arrays → turn an options array such as `new Length(['min' => 3])` into `new Length(min: 3)`. Give custom constraints named constructor parameters for their public options. Exercise an invalid value in the same validation group.
- `profiler.xml` or `wdt.xml` imports → use the PHP routes and exercise the dev toolbar.
- Workflow `Event::getWorkflow()` → inject the intended `WorkflowInterface`. Exercise each affected workflow when several share listeners.

[7.3.0 release](https://symfony.com/blog/symfony-7-3-0-released), [Upgrade notes](https://github.com/symfony/symfony/blob/v7.3.0/UPGRADE-7.3.md)
