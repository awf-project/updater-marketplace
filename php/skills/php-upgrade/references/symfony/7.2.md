# Upgrade from Symfony 7.1 to 7.2

- In YAML service arguments change `!tagged` to `!tagged_iterator` and preserve its tag and index. For a pool that enables tags on the `cache.app` adapter, use `cache.app.taggable` and invalidate a tag shared by two cached items.
- `secrets:decrypt-to-local` automation → account for nonzero status on unreadable secrets. Test how the runner handles partial output.

[7.2.0 release](https://symfony.com/blog/symfony-7-2-0-released), [Upgrade notes](https://github.com/symfony/symfony/blob/v7.2.0/UPGRADE-7.2.md)
