# Upgrade from Symfony 8.1 to 8.2

This guide covers **8.2.0-BETA2**, published on November 13, 2026. Use it for projects testing the 8.2 prerelease. For a stable-only upgrade, check the published tags before selecting a target. [Symfony 8.2 release status](https://symfony.com/releases/8.2)

## Container compilation and workers

- If a bundle section uses `enabled: '%env(bool:FOO)%'` with `canBeEnabled()` or `canBeDisabled()`, supply the variable when compiling the container. A false value now disables the section and an undefined value fails compilation. BETA2 also resolves `asset_mapper.server` at compile time. Warm the cache with the value available during the actual image build and check whether the affected service is registered.
- For a custom `ServicesResetterInterface` implementation, change the signature to `reset(bool $shutdown = false): void` and forward the flag through decorators. If a shared worker service retains per-message state and relied on an implicit reset, register its reset method with `kernel.reset`. Process two messages in the same worker and check the second starts with clean state.
- For `#[AutowireCallable]` or `#[AutowireMethodOf]`, the target is now constructed on first call. Set `lazy: false` where construction at injection time performs required initialization or where the target method cannot be reflected.

## HTTP, routes and validation

- If URL generation relies on an invalid route parameter throwing `InvalidParameterException`, set `framework.router.strict_requirements: true` in the affected environment. With debug disabled the new default is `null` and the generator can emit an unusable URL. Test generation with a value outside the route requirement under `APP_DEBUG=0`.
- For clients of JSON errors produced by `SerializerErrorRenderer` and `ProblemNormalizer`, accept `application/problem+json`. In functional tests for those responses, use `assertResponseFormatSame('problem')`. Keep ordinary JSON endpoint assertions scoped to their own media type.
- If `#[UniqueEntity]` checks an array field or a to-many association, the default `findBy` now raises `ConstraintDefinitionException`. Set `repositoryMethod` to a query that implements the intended uniqueness rule. Test both an existing match and a distinct entity.

## Console automation

- When both `app:import` and `app:import:users` exist, `app:import users` selects the subcommand. Change jobs that mean to pass the literal argument to `app:import -- users`. Verify which handler runs with the scheduler’s actual argument list.
- A Console process stopped by an unhandled `SIGTERM` now exits with 143. If systemd treats an intentional stop as a failure, handle the signal in the command or add `SuccessExitStatus=143` to that unit. Check the exit status after stopping the service.
