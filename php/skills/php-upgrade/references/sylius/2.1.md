# Upgrade from Sylius 2.0 to 2.1

- Symfony 7.1 pins → resolve Symfony 7.2+ before installing Sylius 2.1.
- Custom admin Twig Hooks → move the dashboard `new_customers` hook to `pending_actions` and order actions to `sylius_admin.order.show.content.header.title_block.actions.list`. Verify visibility and single rendering.
- If the shop overrides the add-address button, move `sylius_shop.account.address_book.index.content.main.buttons.add_address` to `sylius_shop.account.address_book.index.content.main.header.buttons.add_address`. Open the address book and follow the button to the form.
- When custom admin assets import core controllers, update paths such as `taxon-tree` to `@sylius/admin-bundle/taxon-tree`. Rebuild the admin entry point and expand a taxon in the tree.
