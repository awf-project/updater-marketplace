# Upgrade from Sylius 1.13 to 1.14

- `Sylius\Component\Resource` imports or `ResourceControllerEvent` → move to the matching `Sylius\Resource` types and `GenericEvent`. Test create and update listeners.
- Where cart code decorates `sylius.order_item_quantity_modifier`, retarget the decorator to `sylius.modifier.order_item_quantity`. For `sylius.order_item_quantity_modifier.limiting`, the listed replacement is `sylius.modifier.cart.limiting_order_item_quantity`. Change the target and place a cart update through the limiting path.
