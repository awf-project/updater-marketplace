# Upgrade from Sylius 2.2 to 2.3

- Shop decorators for `sylius.user_checker.enabled` → adapt to `sylius.user_checker.verification_aware_enabled` and the email verification checker. Test enabled, disabled, and unverified users.
- Custom promotion/coupon implementations and generators → implement `isTrackUsage()` and applicable `setTrackUsage(bool $trackUsage)`. Retain the true default and test counters and cancellation with tracking on and off.
- Raise PHP to at least 8.3 on CLI, workers and web processes still on 8.2 before resolving the 2.3 packages. When a custom promotion eligibility checker reads an existing nonzero usage count, skip the usage-limit check if `isTrackUsage()` is false. Exercise an order with that stored count.
